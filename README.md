# Lookauramax Website

Official marketing site for Lookauramax — landing page + blog.

- `index.html` — landing page (landing page, SEO/AEO/GEO, pricing, FAQ)
- `logo.png` — founder logo (do not alter, do not regenerate)
- `blog/` — 12 SEO blog posts + hub index
- `robots.txt`, `sitemap.xml`
- `netlify.toml` — Netlify config (static site, no build step)

## Deploy

Connected to Netlify with GitHub auto-deploy: every push to `main` redeploys the site automatically (~1 min). No manual upload needed.

- Never add fake reviews, ratings, stats, or testimonials.
- Never claim AuraScan is AI — it is a rule-based estimate.
- Never claim spot-reduction / mewing / chewing / face-yoga fat-burning.
