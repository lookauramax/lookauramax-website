# Lookauramax Website

Official marketing site for Lookauramax — landing page + blog.

- `index.html` — landing page (landing page, SEO/AEO/GEO, pricing, FAQ)
- `logo.png` — founder logo (do not alter, do not regenerate)
- `blog/` — 66 guides + hub index
- `robots.txt`, `sitemap.xml`
- `vercel.json` — Vercel config (static site, no build step)

## Deploy

Connected to Vercel with GitHub auto-deploy: every push to `main` redeploys the site automatically (~1 min). No manual upload needed.

## Rules

- Never add fake reviews, ratings, stats, or testimonials.
- Never claim AuraScan is AI — it is an Aura Intelligence estimate with clear, explainable checks.
- Never claim spot-reduction / mewing / chewing / face-yoga fat-burning.
- Pricing: India ₹199/₹399/₹599/₹999, US $9.99/$19.99/$29.99/$49.99, trials 7/7/7/14 days, 3-Month = Best Value, Yearly = Best Savings Per Month. No Weekly, no Lifetime, no permanent Free.
